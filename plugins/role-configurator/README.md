# role-configurator

Design and configure multi-agency role and workflow structures for BPA services.

## Commands

| Command | Description |
|---------|-------------|
| `/configure-roles <id> [--wizard]` | Design or edit roles and status transitions |
| `/audit-workflow [instance]` | Check workflow completeness across all services |

## Agents

| Agent | Description |
|-------|-------------|
| `workflow-designer` | Expert agent for complex multi-agency workflow design |

## Workflow patterns

Single agency · Two-stage approval · Multi-track (by applicant type) · Tiered by risk level
