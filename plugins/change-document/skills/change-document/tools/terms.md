## Howto: say it, sentence by sentence (Frank, 04-08-2026)

He read "all 63 working row determinants compare against a specific value; ours were the only ones using !=" and answered: I do not know what that means. Nothing in it is a word a designer sees on a screen. Say it this way instead.

| instead of | say |
|---|---|
| `!=`, `=`, `>`, operators as symbols | is not, is, is more than |
| `None`, `null`, empty value | the question has no answer yet |
| `effectsIds`, `rowDeterminantId`, any key in prose | the effect on Dividend rate, the condition on question 1 |
| the determinant compares against a value | the condition reads question 1 and asks whether the answer is "Yes, unpaid years carry over" |
| a row determinant | the condition that looks at one row of the grid, and name the grid and the question |
| 63 of 67 determinants do X, so ours is wrong | counting other conditions is not evidence; say what THIS condition reads and what the field holds |
| the component has no default | the question starts empty for every applicant |
| the publish did not carry effectsIds | name the object and stay inside what you saw: "on the draft screen the Dividend rate question shows no condition at all, while the design carries one". Do NOT turn one read into a rule about publishing: that claim was made on 04-08-2026 and withdrawn the same day |
| the value is No | the condition compares the stored answer "no dividend preference", which the citizen sees on the screen as No |
| hide field X for type Y | X starts Deactivated, Hidden and Disabled; the effect Activates, Shows and Enables it when the condition is met |
| the effect is on the field | say which component carries the effect: the field, or the column that holds it. Frank, 04-08-2026: put it on the column, or the empty column stays on the screen as a dashed box |
| the bot writes to the register | the data bot sends the answers to the GDB Legal Persons table |
| verified, green, confirmed | say which of the two: built and published is a design claim, proven needs a run on a screen, with its date and its evidence |
| design-verified, runtime-proven, design-side, runtime-side | Frank, 06-08-2026 ("the five-No path is design-verified" — "I don't have any idea what you're referring to"): these are report words, never reply words. Say instead: "I read it in the form's settings" versus "I saw it working on the screen", with the date |
| any invented hyphen-label for a situation (the five-No path, the OFF-state, the read half) | name the person and the thing: "a class that answers No to all five questions", "the field's starting state". If the label is not on a BPA screen or in the Glossary, the sentence is rewritten before sending (three-tests rule) |
| the publish failed | the publish is still running; the status tool cannot tell running from failed inside the first half hour |
| 303 components changed | a publish rewrites every component, so two saved copies taken across a publish cannot be compared |
| one component shows X, so the publish dropped Y | one component is never a census; say what was read and how many were read, or read them all |

**The test before sending: could Frank act on this sentence without asking what a word means.** If a word is not on a BPA screen and not in the Glossary, it does not go in a message.

**The human page for all of this**: [glossary.html](../../../knowledge/glossary.html) — the sentence to write sits on each element, and §"How to say it" holds the evidence rules and the three tests. This file stays the machine list the check reads.
