# The pre-verbal principle (a.k.a. the Teletubbies principle)

The core design philosophy behind the screens-first method. Every screen produced with this plugin is judged against it **before** it is shown.

## Definition

Some television made for babies communicates pre-verbally: it conveys a message simply and strongly, mainly visually, to a part of the mind that understands before language does. Every tool and every page built with this method must do the same: be **understood before it is read**, or predispose the reader to understand, or convey a spirit/feeling. Words confirm what the eye already grasped.

## The register guard-rail (what it does NOT mean)

Not childish, not twee, not dumbed-down. The principle means **deep, simple, full of meaning** — simplicity as the most direct path to meaning, with full dignity. **Simple ≠ simplistic**: the register stays adult and serious; it is the DEPTH that must arrive pre-verbally.

## Why

These products often serve entrepreneurs in low-literacy, low-tech contexts, and busy officials. The first five seconds decide whether the tool feels safe and obvious. Judge every deliverable against this first.

## The 5-second test

Mentally cover all text — does the screen/page still say:

1. *what this is*,
2. *what to do*,
3. *whether all is well*?

If not, redesign before writing copy. If a screen needs its help sheet to be understood, the screen is not done.

## The six operational controls

1. **The 5-second test** (above) — run it on every screen before showing it.
2. **State speaks by color and shape**, consistently: one calm/attention/blocked visual language across the whole product (e.g. draft = amber, confirmed = green), never decorative color.
3. **One ownable symbol per concept**, reused everywhere — navigation by recognition, not recall.
4. **The gesture carries the meaning:** solemnity by a continuous slide (not a warning paragraph), a door (not a wall) for a missing condition, a badge that flips when something lands.
5. **One-breath sentences**, one idea per line; plain-language questions instead of domain vocabulary ("Paid how?" — never "consideration").
6. **Numbers with visual mass** where they matter (bars, proportions, a highlighted total row) — quantities perceived before read.

## Where it lives in the method

The check is step 9 of the bundled `screens-first-design` skill, and the bundled `assets/reference-mockup.html` embodies controls 2–6 (state badges and bands, one icon set, slide-to-confirm, one-breath help blocks, the total row with visual mass).
