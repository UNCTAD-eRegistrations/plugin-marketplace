# service-builder

Design and build new eRegistrations services with forms, determinants, roles, and registrations.

## Commands

| Command | Description |
|---------|-------------|
| `/build-service [name] [instance]` | Interactive guided service build |

## Agents

| Agent | Description |
|-------|-------------|
| `service-architect` | Expert BPA service architect for complex builds |

## Skills

| Skill | Description |
|-------|-------------|
| `bpa-service-design` | Form design patterns, determinant logic, role models |

## Build Phases

1. Service shell
2. Form design (sections, fields, grids)
3. Conditional logic (determinants + effects)
4. Roles & workflow (status transitions)
5. Registrations & institutions
6. Document requirements & costs
7. QA (debug scan) & publish

## Requirements

- Authenticated BPA MCP server
