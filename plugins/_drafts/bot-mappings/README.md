# bot-mappings

Create, configure, and manage BPA bot integrations and field mappings.

## Commands

| Command | Description |
|---------|-------------|
| `/bot-mappings <id> [instance] [--suggest]` | Manage bot mappings for a service |

## Features

- Health summary for all bots in a service
- AI-powered mapping suggestions (`--suggest` flag)
- Atomic bulk mapping replacement
- Bot validation after changes

## Requirements

- Authenticated BPA MCP server
